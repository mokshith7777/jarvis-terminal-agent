Terminal first · Telegram remote channel

Control your machine with intent.

JARVIS is an open-source Python agent that turns natural-language requests into validated actions. Telegram is the remote interface. The terminal remains the command center.

View RepositoryInstall

Core systems

01 · Agent

Structured planning

OpenAI-compatible models produce constrained JSON actions with a deterministic fallback.

02 · Telegram

Remote control

Allowlisted Telegram users can send intent to the same local runtime.

03 · Security

Explicit policy

Commands, SSH hosts, and remote actions are validated before execution.

Install

python3 -m venv .venv
source .venv/bin/activate
pip install -e .
jarvis setup
jarvis

Telegram

Configure your bot token and numeric Telegram user allowlist locally, then start the remote channel:

jarvis setup
jarvis-telegram

Contacts sent through Telegram are stored locally and scoped to the authorized Telegram user.

Security model

No shared API keys
No shell injection
Allowlisted SSH commands
